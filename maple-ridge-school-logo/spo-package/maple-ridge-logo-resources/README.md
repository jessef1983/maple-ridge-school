# Maple Ridge School Logo Resources

SharePoint/KB-ready staff resource package.

## Contents

- `maple-ridge-logo-resources.md` — primary staff-facing Markdown resource with collapsible HTML sections.
- `images/` — logo files in practical formats.
- `email-signature/` — staff email signature generator.
- `label-builder/` — current Avery 94510 round-label builder.
- `image-manifest.json` — machine-readable logo metadata.

The Markdown uses relative links so the package can be stored together in SharePoint or another document library.
